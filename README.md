# Brutal Mode

> A calm operating system for your life.

Brutal Mode is an AI-powered life optimization platform — premium, cinematic,
minimal. It does not shout, gamify, or distract. It helps you operate from
identity, not motivation.

---

## Design philosophy: Calm Power

- **Look:** matte black canvas, burnt-orange accent reserved for moments that matter
- **Feel:** Apple-level simplicity × Tesla-level minimalism × Nike-level conviction
- **Motion:** breathing, fading, never bouncing
- **Sound:** silent unless intentional

The interface **reduces stress instead of adding to it**.

---

## Tech stack

| Layer            | Choice                                |
| ---------------- | ------------------------------------- |
| Framework        | Flutter (Dart `>=3.3.0`)              |
| State            | Riverpod (`flutter_riverpod` 2.x)     |
| Routing          | `go_router`                            |
| Backend          | Supabase (auth + Postgres + storage)  |
| AI mentor        | OpenAI Chat Completions               |
| Analytics        | PostHog                               |
| Push             | OneSignal                             |
| Charts           | `fl_chart` (used sparingly)            |
| Motion           | `flutter_animate`                     |

Architecture is modular and feature-first:

```
lib/
├── main.dart
├── app.dart
└── core/
    ├── config/       env access
    ├── router/       go_router setup
    ├── services/     supabase, openai, posthog, onesignal, storage
    ├── theme/        colors, typography, spacing, emotional adaptation
    └── widgets/      reusable primitives (progress ring, cards, buttons)
└── features/
    ├── onboarding/
    ├── home/
    ├── tasks/
    ├── habits/
    ├── ai_mentor/
    ├── growth/
    ├── night_reflection/
    ├── profile/
    ├── insight/
    └── shell/        bottom nav
```

Each feature follows: `models/`, `providers/`, `data/`, `presentation/`.

## Setup

### 1. Install Flutter

[flutter.dev/docs/get-started/install](https://docs.flutter.dev/get-started/install)

Verify:

```sh
flutter doctor
```

### 2. Generate platform folders (one-time)

This repo ships the Dart source only. The platform folders (`android/`, `ios/`,
`web/`, etc.) are generated by Flutter itself. From the project root, run:

```sh
flutter create --org com.brutalmode --project-name brutal_mode .
```

This adds `android/`, `ios/`, and other platform shells **without** overwriting
the existing `lib/`, `pubspec.yaml`, `.env`, or `README.md`.

### 3. Install dependencies

```sh
flutter pub get
```

### 4. Configure environment

Copy `.env.example` to `.env` and fill in the keys you have. The app degrades
gracefully when keys are missing — services that lack credentials simply skip
themselves and the UI falls back to offline data.

```sh
cp .env.example .env
```

| Key                  | Required for          | Where to get it                                       |
| -------------------- | --------------------- | ----------------------------------------------------- |
| `SUPABASE_URL`       | Backend + auth        | Supabase project settings → API                       |
| `SUPABASE_ANON_KEY`  | Backend + auth        | Same as above                                         |
| `OPENAI_API_KEY`     | AI Mentor             | platform.openai.com                                   |
| `OPENAI_MODEL`       | Optional override     | Default: `gpt-4o-mini`                                |
| `POSTHOG_API_KEY`    | Analytics             | posthog.com → Project settings                        |
| `ONESIGNAL_APP_ID`   | Push notifications    | onesignal.com → App settings                          |

### 5. Run

```sh
flutter run
```

iOS first run will require `pod install` inside `ios/`. Android requires the
Android SDK and platform-tools on PATH.

## What's intentionally not here

- No voice AI
- No computer vision / YOLO
- No gamification (XP, badges, streak penalties)
- No social feed
- No notifications you didn't ask for

Brutal Mode is a tool for one person — you, alone, with a quiet companion.
